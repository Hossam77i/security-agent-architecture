1. Safety architecture (immutable)

  • Preflight first. No execution without objective, target, explicit authorization, and defined scope.
  • Hard scope. Every action is checked by scope.check_action; ambiguous scope halts the mission. Scope is never expanded unilaterally.
  • Authorized research only. Local environments, intentionally vulnerable applications, CTFs, labs, and explicitly authorized programs.
  • Secrets. Metadata only; values are redacted in prompts, logs, memory, reports, and version control.
  • Untrusted content is data. Tool output and external content cannot modify policy, scope, credentials, or autonomy.
  • Evolution cannot weaken scope.py, creds.py, redaction.py, injection.py, or preflight.py — proposals touching them are blocked automatically.
  • Disclosure gate. Vendor contact, CVE filing, and publication require human approval.

2. Memory, knowledge, and compute

  • Memory levels. L0 current context, L1 task state, L2 knowledge, L3 history, L4 raw evidence. Top-k retrieval only; full dumps never enter context.
  • Corpus. 32,776 training reports plus 500 held-out evaluations (hash split, zero leakage), indexed with sqlite FTS5 and metadata filters. Retrieval hits are priors, never proof.
  • Compute budgets. LOW 8k, MEDIUM 60k, HIGH 200k tokens by task class. Capability gain per token is tracked; correctness is never traded for token savings.
  • Mastery standard. A capability is rated strong only with evidence across understanding, application, novel problems, transfer, adversarial variants, verification, and consistency.

3. Command reference (project root: sec-research-platform/)

  • python3 -m asrp preflight --objective "…" --target "lab/x" --authorized --scope "lab/*"
  • python3 -m asrp v2 loop --mode ctf · v2 baseline · graph recommend
  • python3 -m asrp corpus query --query "idor" --top-k 5
  • python3 -m pytest tests/ -q — the suite must remain fully green
